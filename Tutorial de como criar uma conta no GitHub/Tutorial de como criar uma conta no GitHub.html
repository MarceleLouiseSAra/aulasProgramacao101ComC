Tutorial de como criar uma conta no GitHub

  1. Navegue até https://github.com/signup. Você também pode apertar a tecla Ctrl, segurá-la e clicar, com o botão esquerdo do mouse, no link acima;
  1. Em seguida, clique em ”Continue with Google”, para se inscrever usando a sua conta pessoal do Google, a mesma do G-mail;
  1. Ou, se preferir, preencha os campos do formulário para criar sua conta pessoal.

Durante a inscrição, será solicitado que você verifique seu endereço de e-mail. Sem um endereço de e-mail verificado, você não poderá concluir algumas tarefas básicas GitHub , como a criação de um repositório.

Na sua página de perfil há um menu superior com algumas opções. Uma dessas opções é a aba “Repositórios”, onde você pode isolar um projeto. Você pode ter quantos quiser, desde que sejam públicos. Para criar um novo repositório, clique no botão verde à direita, em que está escrito “Novo” e há o símbolo de um livro.

Dê um nome para o seu repositório e, opcionalmente, uma descrição.

Uma vez criado o seu repositório, você pode subir arquivos lá. Mais especificamente, você pode guardar o seus códigos de computador no repositório, preservando a extensão (ou seja, se é um código escrito em linguagem C, C++, Python etc.) e os highlights (trechos de código coloridos que sinalizam palavras reservadas).

Para isso, clique em “Adicionar arquivo”, à esquerda do botão verde.

Aparecerá um dropdown com duas opções; clique em “Carregar arquivos”.

Encontre, nas pastas do computador, os programas que deseja guardar no repositório. Clique no programa, segure e arraste para o retângulo principal.

Finalmente, adicione uma pequena descrição daquele arquivo e clique em “Confirmar alterações”, no botão verde na parte inferior da página.

Pastas inteiras contendo vários arquivos também podem ser carregadas no Github.

Para visualizar a página do repositório, clique no nome do repositório, logo após o seu nome de usuario no Github, na barra superior, no canto esquerdo da tela.
